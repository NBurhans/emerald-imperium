# MANIFEST

Machine-readable index for pulling this repo back into a working session.

## Fetching

```bash
python3 tools/fetch.py --user YOUR_GITHUB_USERNAME                 # data + docs
python3 tools/fetch.py --user YOUR_GITHUB_USERNAME --all           # everything
python3 tools/fetch.py --user YOUR_GITHUB_USERNAME --set pipeline  # one set
```

Or pull a single file directly:

```
https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/emerald-imperium/main/<path>
```

`raw.githubusercontent.com` is reachable from a Claude session, so anything listed
below can be read back without re-uploading it.

### pipeline/ — dependency order

```
build_checkpoints.py -> build_availability.py -> prep_scoring.py
  -> score.js            (needs the calc; ~5 min, 63,045 rows)
  -> archetypes.py -> valuation.py -> ship.py -> workbook.py -> readme.py
```

`imperium_gen.js` is the Generation adapter, `calc_batch.js` the batch damage runner,
`verify_damage.py` an independent hand implementation of the damage formula.
`p5_stage1/2/3.py` are the audits and can be re-run against any restored bundle.
`build_app_data.py` + `app_template.html` rebuild the dex.

**`score.js` needs `RadicalRedShowdown/damage-calc` at commit `7f35400`** cloned into
`pipeline/calc/` and compiled with `npm install && npx tsc -p .`. Nothing else needs
the network.
